# Lean formalizations of known mathematics

This folder is for OEIS statements that already have mathematical proofs. Credit the original proof and explain the contribution of the formalization. Record whether an exact public Lean proof already exists; this category by itself does not claim a first Lean formalization.

No result has been imported into this category yet. The research audit identifies candidates, but their sources, attribution, licenses, and build must be checked before publication in this repository.

For each future result, add `AXXXXXX/SOURCE.md` and `AXXXXXX/PROOF.md`, with the formal source under [`LeanOeisProofs/KnownResults/`](../../LeanOeisProofs/KnownResults/).
