# Classification under review

This folder is for verified OEIS results whose novelty classification is unresolved: for example, a prior general theorem may already imply the result, or an existing Lean formalization may overlap with it. State the specific unresolved issue and link the evidence. A successful Lean check alone does not settle novelty or source fidelity.

No result has been imported into this category yet. Unfinished proofs are not published as completed results here.

For each future result, add `AXXXXXX/SOURCE.md` and `AXXXXXX/PROOF.md`, with the formal source under [`LeanOeisProofs/UnderReview/`](../../LeanOeisProofs/UnderReview/).
